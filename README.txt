COACHING FLAG FOOTBALL PRINCIPLES — COURSE MATERIALS WEBSITE
Updated October 22, 2026

START PAGE: index.html (also available as coaching_flag_football_materials.html)

HOW TO PREVIEW
1. Extract the entire ZIP file.
2. Open index.html in a web browser, or visit the published site root.
3. Use the Part/Chapter navigation bar to find sections.
4. Select a form/worksheet title or Open to display the PDF preview in a new browser tab.
5. Select Download to save the editable original Word (.docx) form or worksheet.

COMPLETE FORM AND WORKSHEET PACKAGE
All nine forms and one worksheet named in the source course outline are linked.
The 10 original DOCX files were provided in coaching_flag_football_site_WCAG22_AA(1).zip.
Their original files have not been renamed or edited. Ten PDF browser-viewing
copies have been generated from the supplied DOCX documents.
Only files actually referenced in the course HTML are included.

RESOURCES THAT HAVE NOT BEEN PROVIDED
The 11 optional reading excerpts listed in the outline were not part of the
uploaded ZIP. Those citations remain as visible text with 'File not yet
supplied' labels; no non-working open/download links were added for them.

PACKAGING
The website and resources directory must remain together, with these paths:
  coaching_flag_football_materials.html
  resources/forms/*.docx
  resources/forms/*.pdf

The 4 Part and 18 Chapter navigation destinations are local to the HTML file.
No internet connection is needed to inspect the local copy, except for any
browser-specific handling of Office files. PDF previews open natively in
most modern browsers.

CHECKS
All 10 form/worksheet numbers and displayed titles were checked against the
Word originals. All resulting relative file links were checked inside the ZIP.
See coaching_flag_football_resource_link_manifest.csv for each URL.

ACCESSIBILITY

Word documents and derived PDF previews have not been fully audited or remediated
for document-level accessibility. Review these before claiming full-site
conformance. Refer to ACCESSIBILITY_README.txt and the included WCAG report.
